Proportional control

Explain how a proportional controller sets its output, and why too much gain makes the system swing.

1 interactive proof5 sections
Part 1

A controller acts on the error

A controller compares a measured value with a target value and decides how hard to push the system. The difference between the target and the measured value is called the error.

error = target minus measured

If the target is 50 degrees and the room is at 42 degrees, the error is 8 degrees.

The next question is how hard to push for a given error.

Part 2

The output grows in step with the error

A proportional controller sets its output proportional to the error. The factor between them, Kp, is called the proportional gain.

output = Kp × error

You can think of Kp as a volume knob. A bigger Kp means a louder response to the same error: the louder the response, the harder the heater pushes.

With Kp = 2 and an error of 8 degrees, the output is 16 units of heater power. With Kp = 5 the same error gives 40 units.

Key pointA larger gain makes the system react faster, but only up to a point.

That limit is the subject of the next part.

Part 3

Too much gain makes the system swing

If the gain is too high the system overshoots the target and starts to oscillate around it.

WarningIn a real heater this can damage the equipment, so never raise the gain without a safety limit. This will be on the exam.

Here is why it happens. The controller pushes hard because the gain is high, and the system gets past the target because of its inertia. Now the error has the opposite sign, so the controller pushes back just as hard. This repeats, and the temperature swings above and below the target.

The overshoot, then, is the amount by which the system passes the target, and oscillation is the repeated swing.

So the gain has to stop short of that swing, which leaves the question of how to choose it.

Part 4

Engineers pick the gain by trial

In practice, engineers pick Kp by trial:

  • Start with a low Kp.
  • Raise it until the response is fast.
  • Stop just before oscillation begins.

For the heater in the lab, oscillation starts at about Kp = 8.

Definitions

Error

Proportional gain

Overshoot

# Lectures

Interactive lecture pages served with GitHub Pages.

- Lecture list: https://voidnor1807-maker.github.io/voidnor1807/
- Cellular changes: https://voidnor1807-maker.github.io/voidnor1807/cellular-changes/

Each lecture is one self-contained HTML file at `<slug>/index.html`, with no external fonts, scripts or images. Slugs are lowercase ASCII. To add a lecture, add its folder, then list it in `index.html` and `lectures.json`.
